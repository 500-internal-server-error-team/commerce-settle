# 프로젝트 범위와 검증

기본 범위는 단일 판매자·단일 상품 주문, 모의 결제·전액 환불, 구매확정 후 정산·지급입니다. 세부 계약은 [지원 범위](design.md#2-해결-범위)와 [업무 정책](policies.md)을 따릅니다. 기능별 담당과 작업 진행은 이슈·PR에서 관리합니다.

## 기술 검증 목표

[지속 결제 처리량](../README.md#성능-목표와-검증)과 [선착순 집중 부하](design.md#선착순-이벤트-집중-부하)를 구분합니다. [검증 지표와 완료 기준](design.md#검증-지표와-완료-기준)으로 정상·중복·미확정·재시작·환불/지급 경쟁과 최종 금액을 대조합니다. 목표·시험 입력은 실측 결과와 구분합니다.
